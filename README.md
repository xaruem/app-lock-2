# sim-menu v2.2

## Первая сборка (один раз): ключ подписи
1. Репозиторий должен быть ПРИВАТНЫМ.
2. GitHub -> Actions -> "Create keystore (run once)" -> Run workflow.
3. Скачай артефакт keystore-secrets, открой secrets.txt.
4. Settings -> Secrets and variables -> Actions -> New repository secret. Создай 4 секрета
   с именами и значениями из файла: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
5. Сохрани secrets.txt в надёжном месте (без ключа обновить приложение нельзя), удали артефакт в Actions.

## Сборка APK
Actions -> Build APK -> Run workflow -> артефакт sim-menu-apk -> sim-menu-release.apk.
Каждая следующая версия, собранная с теми же секретами, ставится поверх старой, сейф сохраняется.

## Раздел «Данные» (v2.1)
В SIM-меню есть пункт «Данные»: сетка приложений, которые ты отметил галочками (карандаш вверху). Нажатие запускает приложение. Пароль не нужен.
Сам значок с рабочего стола прячется средствами телефона (Redmi: Настройки -> Рабочий стол -> Скрытые приложения, название зависит от версии MIUI).
При сворачивании sim-menu возвращается на обычный экран SIM-меню.

## Поделиться -> в сейф (v2.2)
В галерее выбери фото или видео (можно несколько) -> «Поделиться» -> sim-menu. Файлы сразу шифруются, пароль не нужен, и ты возвращаешься в галерею. Видео кладётся без сжатия (сожмёшь потом в сейфе через «Пересжатие»). Оригиналы удаляются позже, когда откроешь сейф. Сейф должен быть уже создан.
